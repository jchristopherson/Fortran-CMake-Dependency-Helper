# Contributing

Thanks for your interest in improving the Fortran CMake Dependency Helper.

## How to contribute

1. Fork the repository.
2. Create a feature branch for your change.
3. Keep your changes focused and small.
4. Run the project checks before submitting a pull request.
5. Open a pull request with a clear summary of the change.

## Development setup

```bash
npm install
npm test
npm run compile
```

## Project expectations

- Keep TypeScript code clean and type-safe.
- Add or update tests for behavior changes when practical.
- Prefer small, targeted fixes over broad refactors.
- Update documentation when user-facing behavior changes.

## Reporting issues

Please include:

- a short description of the problem
- the exact command or UI action that triggered it
- any relevant CMake output
- expected vs actual behavior

## Pull request checklist

- code compiles
- tests pass
- behavior is documented if needed
- screenshots or docs are updated for UI changes
